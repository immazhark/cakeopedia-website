## Findings that change implementation

- Sanity Free has public-only datasets and Administrator/Viewer, not restricted Editor.
- D1 Free quota exhaustion can stop queries; atomic batch needs real replay/failure tests.
- Resend has daily and monthly quotas and a 24h idempotency window, not eternal dedup.
- Turnstile requires server verification; single-use tokens complicate lost-response retry.
- Current Texas rules expanded in 2025; classification/registration/labels/delivery need
  owner-specific review. No compliance determination is made by this documentation.
- A private home address must not be exposed for LocalBusiness rich-result completeness.
- Static HTML is appropriate for SEO; special AI files or guaranteed rankings are not required.

## Stage application

Pre-build: intent/page map and truthful content model. Build: static HTML, semantic
navigation, accessible components and correct status/canonical/metadata. Prelaunch:
protected/noindex previews, final-domain sitemap/redirects, schema factual validation,
phone and form recovery. Postlaunch: GSC/Bing, eligible local profiles, genuine reviews
and actual outcomes. OAI-SearchBot versus GPTBot policy is a separate choice.

Limited local official-page benchmarks: Cakes by Cassandra illustrates a detailed
home-bakery form; Quack's separates custom quotation; Katherine Elizabeth Cakes uses
bespoke portfolio/process positioning. These are not conversion or visual performance
audits, revenue evidence or proof of Cakeopedia superiority.
